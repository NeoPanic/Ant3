# 蚁群群聊

控制台 `/chat` 将共享任务板与执行记录呈现为群对话。每次发送直接调用已有的任务发布接口；用户原话保存为任务内容，名称取前 50 个字符，默认验收标准要求回应输入中的目标、约束、证据与阻塞。仍由原有选型或个体自选、原子认领、拆分、成员消息与验收机制推进。群聊不设置固定角色、主持人、候选名单或新的任务调度器。

同一根任务的多个成员分别发言，身份来自真实 instance 与 run。任务级接单、分工、进度、工具动作、错误和模型正文按事件时间呈现；正在生成的文字持续追加到对应成员的消息。任务筛选保留同一项工作的全部参与者。模型正文属于成员输出，执行成功与验收通过仍以任务状态为准。

## 流式传输与恢复

Worker 在三类协议上请求供应商 SSE，文本增量通过既有 LiveOutput 接口进入宿主，每 150 ms 合并写入原有事件表。HTTP 兼容服务若返回完整 JSON，保留整轮回执路径。控制面选型继续使用完整响应。工具调用必须收齐并通过原有校验后才执行；未结束的分片不会成为工具调用。正文以纯文本转义展示，不输出模型 reasoning、工具参数或原始 JSON。

`GET /api/chat/history` 返回最近 200 个相关事件序号；同一事件关联多个根任务时保留全部投影，`root_id` 按根任务过滤，`before` 可加载更早事件。`GET /api/chat/stream?after=SEQ` 读取后续事件，自动重连时优先使用 `Last-Event-ID`；同一序号的全部投影发送后才推进恢复游标。浏览器按事件序号与根任务去重，离开页面关闭订阅。流中断显示断线状态，历史分片不完整时明确标记；结束回执可恢复完整正文。服务关闭时结束订阅，避免长连接阻止退出。

发送结果未知时保留原文及命令键，重试复用已有任务发布的幂等回执；明确拒绝时允许修改输入。轮询更新任务状态时保留输入框和光标，阅读历史时不强制滚到底部。UTF-8 上限为 8,000 字节，中文输入法确认不会触发发送，快捷键为 Command/Ctrl + Enter。

当前入口共用同一个任务板。每条输入独立成任务，不自动改写正在执行的工作，也不向新任务注入其他任务的对话历史。主列表沿用任务板最近 100 项根任务的快照范围，完整旧任务通过任务详情访问。没有新增数据库表或 schema 迁移。

## 参考与取舍

- [AutoGen SelectorGroupChat](https://microsoft.github.io/autogen/stable/user-guide/agentchat-user-guide/selector-group-chat.html)：共享上下文与动态发言选择可帮助理解群聊；本轮保留 Ant³ 自有协调机制。
- [AutoGen Swarm](https://microsoft.github.io/autogen/stable/user-guide/agentchat-user-guide/swarm.html)：成员基于局部信息交接工作，适合用成员身份与事件因果解释过程；界面不添加固定发言顺序。
- [CrewAI Crews](https://docs.crewai.com/en/concepts/crews)：任务、输出与协作过程分开建模；不引入其 sequential/hierarchical 角色流程。
- [Slack agents](https://docs.slack.dev/ai/)：独立对话入口、处理状态和上下文明确的回复，支持持续反馈与按任务查看。

## 验证

协议 fixture 覆盖 UTF-8 跨 chunk、CRLF、增量工具参数、usage、终止帧缺失、Responses continuation、Anthropic 工具块与取消。HTTP 测试确认终止帧到达前可读正文，取消保留已收到前缀；SSE 测试覆盖认证、任务范围、分页、游标恢复与服务关闭。前端测试覆盖多成员分片合并、HTML 转义、历史缺片、幂等重试和中文字节限制。

本地隔离模型桩完成了拆分、双成员执行与重新认领整合；确定性内容标注为联调演示。此证据验证传输与协调契约，不验证真实模型的语义质量。真实供应商的流式兼容性仍需用实际服务验收。
