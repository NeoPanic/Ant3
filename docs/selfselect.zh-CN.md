# 个体自选认领：选型彻底下沉

蚂蚁没有调度员。`ANT3_SELF_SELECT=1` 时，中央选型分类器完全退位，"谁干哪个任务"由个体局部规则决定；控制面只保留物理法则：容量、能量、原子性。

## 机制

- **游走待命池**：上限 8 个待命实例。池成分按验证经验繁殖——各母体份额 ∝ (成功数+1)（Laplace 平滑，新母体有机会），持续失败（≥3 败 0 成）的母体退役。池成分本身是涌现的，不是人预定义。
- **阈值响应**：每个待命个体对开放任务计算刺激（痕迹浓度/(1+拥挤)），以自己的成本调整阈值做 s²/(s²+θ²) 概率响应（splitmix64 种子化抽样）。专家响应弱刺激，新手只抢强任务。
- **原子竞争**：响应者先插入 Run，再以 `UPDATE … WHERE state='pending' AND route_state='unassigned'` 门控认领；败者回滚 Run。同一任务至多一个有效执行者。
- **游走成本**：待命实例每分钟消耗 20 群体能量（群体池 20 万）；耗尽时全池退役——养不起的蚁群自然缩小。
- **幂等认领**：自选 Run 的任务已处于 running/self-selected，Agent 调 `platform.board.claim` 确认所有权（幂等），随后正常执行/拆分/上报。

## 与选型模式对照

默认（开关关闭）走证据引导的中央选型；开启后分类器 stand down，两条路径共享同一套痕迹/能量/审计/黑板物理。评估基线可在同任务同能量下对照两模式的收敛时延与净能量。

## 查询与事件

`GET /api/swarm/pool`：池成员、上限、群体能量。事件：`swarm.self_selected`（个体、刺激、阈值）、`swarm.peer_spawned/peer_retired`（繁殖/退役）、`swarm.colony_starved`。

## 边界

- 池繁殖当前按母体粒度；实例级经验与跨池迁移未实现。
- 自选模式与选型模式互斥（开关切换需重启守护进程）。
