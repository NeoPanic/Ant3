# 当前平台状态

Ant³ 的唯一协调路径是共享任务板：发布工作后，由证据引导的控制面选型或个体自选（`ANT3_SELF_SELECT=1`）决定谁接活，Agent 原子认领、执行或拆分，再把子任务交回任务板。所有任务板 Agent 使用同一协议，实例生命周期由平台管理。启动和模型配置见[使用指南](getting-started.zh-CN.md)，逐项能力及源码落点见[能力索引](capabilities.zh-CN.md)。

## 可用链路

- **共享任务板**：任务发布不绑定实例或 Preset。控制面按能力目录动态选型，实例启动后认领；拆分来源成功后激活子任务，子任务完成后原任务重新可认领以整合结果。选型模型可独立配置，任务、实例和 Run 保留来源。Agent 可上报里程碑与阻塞；根任务执行成功后等待人类评审，通过后归档，退回意见触发重新选型与执行。当前提供 Web、HTTP 与 CLI。
- **信息素痕迹场**：完成/验收/复用/招募按固定权重增强，失败降权，随时间蒸发；局部感知默认只见浓度超阈值的痕迹。板根黑板以 CAS 修订发布发现，冲突按证据强度自动裁决。详见[痕迹场](traces.zh-CN.md)。
- **预算即能量**：根任务能量池派发预留、按 usage 结算、验收回充；饥饿根停止供给并淘汰待认领任务。详见[能量](energy.zh-CN.md)。
- **负反馈与鲁棒性**：失败有界重试、新个体接手；返工链指数冷却与链长上限抑制振荡；拥挤稀释刺激分散工作。
- **点对点消息**：同板根成员通过持久消息交接任务数据，Outbox/Inbox 保证投递与消费可恢复；未知结果须人工处置后才继续派发。
- **文件与验收**：实例读写自己的 UTF-8 文件，发布不可变文件/JSON 快照供同板根成员读取。发布任务时可选独立验证：全新验证器实例按验收标准审计冻结结果，通过自动归档，退回附意见有界返工；人工评审保留最终决定。
- **能力扩展**：提示词包与本地进程工具支持在线安装、固定版本绑定和健康检查。提供[文本统计](../../crates/ant3-plugins/examples/text-inspector/)、[HTTP 读取](../../crates/ant3-plugins/examples/http-reader/)和[工作区 Preset](../../crates/ant3-plugins/examples/workspace-preset/)示例。

任务板 Demo 验证根任务拆分为两项子任务、执行和重新认领整合；内容为确定性演示。真实模型可发布绑定任务板、消息与工作区工具的自定义 Preset，在同一板根内协作。

任务 `completed` 表示已知 Run 执行成功；根任务须由人类评审或独立验证通过，`review_state=accepted` 才归档。人工通过不构成已运行独立验证器的证明。

## 运行边界

平台采用单 daemon、SQLite、本地 Worker 和受信任插件。进程插件以 daemon 所在系统用户权限执行；文件工具限制相对路径和符号链接，但没有 OS 沙箱、多租户授权或多机租约。团队费用没有硬上限，Run 仍受轮次、工具调用次数和超时约束。模型接入提供 OpenAI-compatible Chat Completions、OpenAI Responses、Anthropic Messages 三类非流式协议。

| 本地容量约束 | 默认值 |
| --- | --- |
| 活跃实例及待创建预留 | 256 |
| Worker 槽 | 8；同一实例串行 |
| 每板根任务树任务数 | 64 |
| 拆分深度 / 单次子任务 | 6 / 8 |

任务板通过任务范围、实例能力与事务认领约束执行者，发布者无需提供候选实例。拆分不改写已运行节点；文件证据及 HTTP 回执不能证明外部结论正确。流式模型、远程插件 loader、分布式 Worker、跨根团队费用硬上限、细粒度授权和执行隔离尚未提供（见[路线图](roadmap.zh-CN.md)）。容量值属于输入和调度限制，不构成吞吐性能保证。

## 验证范围

已验证原生 Cargo check、Clippy、Rust 测试、rustdoc、quickstart、HTTP 插件 fixture，以及桌面 Web 的主要操作链路。确定性 Demo 和真实模型均验证了任务板拆分、多实例协作、文件交接与独立验证。浏览器覆盖 1024、1440、1920 px；完整屏幕阅读器、跨浏览器、多机故障尚未完成。单/多 Agent 对照已有确定性契约基线（信息复用与成本代理），真实模型等预算效果对照尚未完成。

能力契约见[共享任务板](task-board.zh-CN.md)、[痕迹场](traces.zh-CN.md)、[能量](energy.zh-CN.md)、[自选](selfselect.zh-CN.md)、[评估](evaluation.zh-CN.md)、[消息](messaging.zh-CN.md)和[工作区](workspaces.zh-CN.md)。目标架构及扩展边界见[架构设计](managed-agents.zh-CN.md)。
