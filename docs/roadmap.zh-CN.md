# Ant³ 路线图

唯一的前瞻清单。已落地的机制见[能力索引](capabilities.zh-CN.md)与各专题文档；本文只列尚未完成的方向，完成一项即移除一项。

## 涌现机制

- [ ] **等能量真实模型对照自动化**：评估基线已支持 `energy_budget` 配置两臂同预算，但运行与报告仍手动；做成可重复执行的对照实验（同任务、同能量、同验收，报告通过率/收敛时延/净能量/信息复用）。
- [ ] **实例级经验与跨池迁移**：经验目前按 Preset 粒度；个体层面的成功率/成本记忆，以及个体在池间迁移（而非整池繁殖）。
- [ ] **自选与选型模式的自动对照**：两模式共享物理法则，需同任务对照数据证明自选的收敛与成本特征。

## 治理与规模化

- [ ] **跨根团队费用硬上限**：能量池目前按根任务；团队/账户级硬上限与供应商限价对账、进行中请求的结算边界。
- [ ] **监督 Worker 与执行隔离**：独立进程 Worker、所有权 fencing、OS 沙箱——"敢放养"的安全前提。
- [ ] **远程控制面与 PostgreSQL**：多机 Worker、网络分区对账、分布式背压。本地 256 实例足够涌现实验，规模化后置。
- [ ] **身份、授权与审批**：Principal/Grant、持久审批、租户隔离、插件作用域授权。

## 运行内核

- [ ] **流式模型输出**：三类协议的非流式循环已验证；流式分片与中断契约待补。
- [ ] **MCP loader 与远程插件**：对外 MCP stdio 已提供；远程 MCP/HTTP 工具加载、进程池与 rollout 待补。
- [ ] **实时事件 SSE**：当前为持久游标轮询；SSE 与断线补读待补。

## 明确不做

- 固定角色流水线 / 预定义任务编排（已删除，不再引入）。
- 蚁群优化求解器意义上的"信息素模拟"——痕迹是协调媒介，不是优化算法。
