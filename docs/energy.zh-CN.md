# 根任务预算与补充能量

每个新根任务默认有 1 亿能量，子任务共享此池。通过模型服务返回的 usage 计算本次调用的输入和输出 token，每个 token 计 1 能量，缓存输入包含在输入数中。无 usage 的调用按配置的未知成本结算。派工预留和待命消耗均为零。

可用余额等于预算加回充，减去累计支出及升级前尚未释放的预留。余额耗尽后，调度器保留待办，已认领的执行者在下一次模型请求前等待。同一时刻已经开始的请求会完成并入账，余额可以暂时为负。等待中的 Run 仍占用 Worker，进程重启按现有中断恢复流程处理。

在任务板的根任务详情选择「补充能量」。同一根任务余额恢复为正后继续执行。接口为 `POST /api/v1/board/tasks/{id}/energy`，请求体为 `{"amount":1000000}`，携带 Idempotency-Key。GET 同一路径查看余额和流水。
