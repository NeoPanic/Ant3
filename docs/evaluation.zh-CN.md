# 涌现评估基线：单 Agent 与对等群体对照

工程正确性和协作收益分别衡量。评估基线用同一任务、同一验收标准、同一确定性执行契约，对照"单 Agent 独立完成"与"对等群体拆分—执行—整合"两条路径，报告质量、成本代理与信息复用指标。基线不预设多 Agent 更优。

## 运行

```bash
cargo test --locked -p ant3-server --test evaluation -- --nocapture
```

输出 `EVAL_COMPARISON` JSON 报告。测试同时断言契约不变量，可直接进入 CI。

## 场景与指标

场景：根任务要求收集三份独立证据摘要并整合。单 Agent 臂在一个 Run 内直接完成；群体臂拆分三个子任务，由对等实例分别执行，再由普通实例读取子任务结果完成整合，人类评审验收。

| 指标 | 含义 |
| --- | --- |
| `completed` / `accepted` | 执行成功与人类验收，两臂必须同时满足 |
| `runs` / `claims` / `splits` | 执行成本代理（Run 数、认领数、拆分数） |
| `reuse_deposits` | 通过任务板复用他人结果的次数（信息素 reuse 沉积） |
| `root_trace_strength` | 根任务结果痕迹的有效浓度 |
| `wall_ms` | 墙钟耗时 |
| `emergence.information_reuse` | 群体是否产生了单 Agent 没有的环境信息复用 |
| `emergence.reuse_per_child` | 每份子任务贡献被整合复用的比例 |
| `emergence.run_cost_ratio` | 群体相对单 Agent 的 Run 成本比 |

当前基线结果：两臂均通过验收；群体臂 `reuse_per_child = 1.0`（每份贡献都被整合读取），单 Agent 臂为 0；群体以 5 个 Run 换取并行证据与可度量的信息复用。

## 边界与后续

- 这是确定性契约基线，验证调度和证据链路，不代表真实模型语义质量。
- 真实模型、等 Token 预算对照依赖用量账本（预算能力落地后启用），报告通过率、引用正确率、工具错误率、费用与返工次数。
- 个体损失鲁棒性（杀掉部分个体后群体仍收敛）尚未支持：当前子任务失败会阻塞根任务，重试/重排队落地后加入该指标。
- 固定调研模板与显式 Goal DAG 作为中央编排对照组保留，不与任务板群体路径混用结论。
